# Send Safe

One file: `index.html`. No build, no server, no tracking.

Deploy: new public repo → upload `index.html` → Settings → Pages → Deploy from branch → `main` / `/ (root)`.

Lock: files, or a whole folder, are bundled and encrypted on-device (AES-256-GCM, random key). Choose how long it stays valid, 1–30 days.
